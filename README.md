# 今天卖什么 · FFXIV Currency Trade Helper

把 FF14 里各种**货币 / 代币能兑换的物品**列出来，配上**当前市场最低挂单价**，
按「每单位货币能卖多少金币」排序，帮你决定手上的神典石、徽章、票据该换什么卖掉。

线上版：**https://smartwsw.github.io/FFXIVCurrencyTradeHelper/**

## 功能

### 货币范围

支持 12 种货币：

亚拉戈诗学神典石 · 亚拉戈数理神典石 · 怪物狩猎的战利品 · 天穹街振兴票 · 双色宝石 ·
宇宙信用点 · 巧手紫票 · 大地紫票 · 巧手橙票 · 大地橙票 · 谢尔达莱青船币 · 谢尔达莱绿岛币

显示顺序与上面一致（诗学在最前，数理紧随其后）。增删货币要同时改两处：
[`build.py`](build.py) 的 `WANTED_CURRENCIES` 和 [`docs/index.html`](docs/index.html)
的 `CURRENCY_NAMES`，只改一处会导致数据被过滤掉或页面不显示。

紫票 / 橙票 / 谢尔达莱青船币 / 谢尔达莱绿岛币这几种兑换表只挂在物品页的
`tradeCurrency` 上（NPC 商店里查不到），还要额外登记到 `build.py` 的 `SHOP_CURRENCIES`。

### 收益排行

- **每单位货币**：`最低挂单价 × 兑换数量 ÷ 货币花费`，是主排序键
- **兑换可得**：一次兑换能卖多少钱
- **均价折合**：用加权均价算的同一指标，可作为「这个价格靠不靠谱」的参考
- **7日均成交**：近 7 天的日均成交件数（右侧小字是 7 天合计）
- 所有列都能点击表头排序

#### 成交量口径

统一按**近 7 天**统计，不使用 Universalis 的 `unitsSold`——那是「返回的最近 N 笔」
成交的件数合计，样本可能横跨数月（实测 100 笔里有 73 天前的成交），当成近期数据会严重失真。

页面按成交流水的时间戳自己切 7 天窗口。为了让窗口内记录尽量完整，拉价时用 `entries=500` 采样。

### 兑换路径

每行物品名下方显示兑换路径。两步兑换会显示成
`一级商店 → 二级商店 经由 中间物 ×N`，并标上「二级兑换」。

有些货币换到的东西本身不可交易，但能**再兑换一次**变成可上架物品——这条路径也算进收益，
成本按「消耗的中间物数量 × 中间物的货币单价」折算。

### 过滤条件

| 条件 | 说明 |
|:--|:--|
| 成交量阈值 | 只看近 7 天日均成交 ≥ 该件数的物品，**默认 50**；填 `0` = 不按成交量筛选 |
| 在售件数 ≤ | 冷门判据 |
| 最低单价 | 只看达到该单价以上的物品 |
| 货币花费 ≥ | 默认 1（不过滤）；调高可滤掉小额兑换 |
| 搜索 | 中文 / 英文 / 日文名均可搜 |

数值筛选停手 250ms 后自动生效（失焦时立即生效），不需要手动点「应用」。

「独占」物品（不可交易、不可上架）永远卖不掉，所以不会出现在列表里。

### 统计范围：大区 / 服务器

下拉框按大区分组，每组**第一项是该大区本身**，后面是区内各服务器：

- 选**大区**（如 `猫小胖（国服）· 整个大区`）：挂单、最低价、成交量都汇总该大区内所有服务器
- 选**服务器**（如 `海猫茶屋`）：只看这一个服务器

默认按大区统计（猫小胖）。可选范围是 Universalis 全量清单（18 个大区 / 126 个服务器，国服四大区在最前）。
切换后页面即时向 Universalis 拉价，两种范围各自独立缓存。

### 价格加载与缓存

页面打开时**直接从 Universalis 实时拉取**当前服务器的价格，并存在浏览器本地：

- 同一服务器 **24 小时内不再重复请求**，之后打开是秒开的
- 服务器名右侧有「更新价格」按钮可强制刷新
- 小字显示「N 分钟前更新，N 小时后过期」

FPS 首次打开约需 1 秒（94 个批次并发拉取）。仓库里**不存价格数据**——那只会在每个提交里
多存一份整块副本，没有收益。兑换表（物品名、图标、商店名）才是静态字典，随仓库发布。

### 界面

- **主题**：自动（跟随系统）/ 亮 / 暗
- **语言**：中文 / EN / 日本語，切换后界面文案与物品名一起变
- **筛选折叠框**：默认展开，可收起（选择记在本地）；收起时按钮上显示生效中的筛选条数

前两项选择都会记住，下次打开保持不变。

## 数据来源

- 兑换表：[Garland Tools](https://www.garlandtools.org/db/)
- 市场价：[Universalis](https://universalis.app/)
- 中文物品名：[Teamcraft](https://github.com/ffxiv-teamcraft/ffxiv-teamcraft) 的国服数据
- 日文物品名：Garland 的日文文档

## 手动修正

Garland 偶尔会标错货币。这类条目记在 [`manual_overrides.py`](manual_overrides.py) 里，
`build.py` 在自动汇总**之后**统一应用，因此不会被下一次自动构建覆盖。
被修正的条目在页面上带一个「手动修正」标记，鼠标悬停有说明。

当前修正：**卓越丸子**（[38808](https://www.garlandtools.cn/db/#item/38808)）
Garland 标成「亚拉戈诗学神典石 ×2」，实际是「大地紫票 ×2」，已挪到大地紫票下。

物品自身的名字、图标、是否可交易仍取自 Garland，这里只描述兑换关系。


## 已知限制

- 收益按最低挂单价算，**不含 5% 市场税**
- 需要额外材料的兑换只计该货币部分的成本，材料成本未折算
- 国服 Universalis 的成交记录有时为空，此时建议结合「在售件数」判断冷热
