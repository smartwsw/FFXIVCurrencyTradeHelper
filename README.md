# 今天卖什么 · FFXIV Currency Trade Helper

把 FF14 里各种**货币 / 代币能兑换的物品**列出来，配上**当前市场最低挂单价**，
按「每单位货币能卖多少金币」排序，帮你决定手上的神典石、徽章、票据该换什么卖掉。

线上版：**https://smartwsw.github.io/FFXIVCurrencyTradeHelper/**

## 功能

### 货币范围

支持 9 种货币：

亚拉戈诗学神典石 · 怪物狩猎的战利品 · 天穹街振兴票 · 双色宝石 · 宇宙信用点 ·
巧手紫票 · 大地紫票 · 巧手橙票 · 大地橙票

### 收益排行

- **每单位货币**：`最低挂单价 × 兑换数量 ÷ 货币花费`，是主排序键
- **兑换可得**：一次兑换能卖多少钱
- **均价折合**：用加权均价算的同一指标，可作为「这个价格靠不靠谱」的参考
- 所有列都能点击表头排序

### 兑换路径

每行物品名下方显示兑换路径。两步兑换会显示成
`一级商店 → 二级商店 经由 中间物 ×N`，并标上「二级兑换」。

有些货币换到的东西本身不可交易，但能**再兑换一次**变成可上架物品——这条路径也算进收益，
成本按「消耗的中间物数量 × 中间物的货币单价」折算。

### 过滤条件

| 条件 | 说明 |
|:--|:--|
| **排除低成交量** | 滤掉卖不动的物品，只留有真实成交的 |
| 成交量阈值 | 冷门判据，默认 5 件/天 |
| 在售件数 ≤ | 另一条冷门判据 |
| 最低单价 | 只看达到该单价以上的物品 |
| 货币花费 ≥ | 默认 1（不过滤）；调高可滤掉小额兑换 |
| 搜索 | 中文 / 英文 / 日文名均可搜 |

「独占」物品（不可交易、不可上架）永远卖不掉，所以不会出现在列表里。

### 服务器

下拉框包含 **Universalis 全量服务器列表**（18 个大区 / 126 个服务器，国服四大区在最前），默认海猫茶屋。
选未预抓的服务器时，页面会即时向 Universalis 拉价。

### 价格缓存

价格拉回后存在浏览器本地，**同一服务器 24 小时内不再重复请求**。
服务器名右侧有「更新价格」按钮可强制刷新，小字会显示「N 分钟前更新，N 小时后过期」。

### 界面

- **主题**：自动（跟随系统）/ 亮 / 暗
- **语言**：中文 / EN / 日本語，切换后界面文案与物品名一起变

两项选择都会记住，下次打开保持不变。

## 数据来源

- 兑换表：[Garland Tools](https://www.garlandtools.org/db/)
- 市场价：[Universalis](https://universalis.app/)
- 中文物品名：[Teamcraft](https://github.com/ffxiv-teamcraft/ffxiv-teamcraft) 的国服数据
- 日文物品名：Garland 的日文文档

## 已知限制

- 收益按最低挂单价算，**不含 5% 市场税**
- 需要额外材料的兑换只计该货币部分的成本，材料成本未折算
- 国服 Universalis 的成交记录有时为空，此时建议结合「在售件数」判断冷热
